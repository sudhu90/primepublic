# PrimePublic

A public repository for Sudarshan's web-based work, demos, and shareable HTML content.

## Overview

PrimePublic is a lightweight static web project hosted through GitHub Pages. It is designed to publish simple web pages, experiments, learning resources, and public-facing content.

## Live Site

Visit the live site here:

[https://sudhu90.github.io/primepublic/]

## Tech Stack

- HTML
- GitHub Pages

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/sudhu90/primepublic.git
   ```

2. Open `index.html` in a web browser to preview the site locally.

3. Update the HTML files as needed.

4. Push your changes to GitHub to publish updates through GitHub Pages.
